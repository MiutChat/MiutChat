# Security Policy

## Supported Versions

The latest version of this project is actively maintained and receives security updates.  
Older versions are not supported.

---

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it responsibly.

📧 Contact: feedback.miut@zohomail.in

Please include:
- A clear description of the issue
- Steps to reproduce the vulnerability
- Any proof-of-concept or screenshots (if applicable)

Do **not** disclose the issue **publicly** until it has been **reviewed** and **resolved**.

---

## Response Policy

- Initial response within 48 hours  
- Regular updates during investigation  
- Fixes are prioritized based on severity  

We appreciate responsible disclosure and your efforts in helping keep this project secure.
